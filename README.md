# DrumCopy — 모바일 드럼 사보

한 박 단위로 리듬을 채워넣어 드럼 악보를 카피하는 웹앱. 빈 오선지에서 **마디 → 박 + 오선 위치(악기) → 리듬 패턴** 순서로 탭해서 채웁니다.

Vite + 바닐라 JS(ES 모듈). 프레임워크·외부 라이브러리·웹폰트·이미지를 쓰지 않아 빌드 결과가 40KB 남짓이고, 한 번 열어두면 오프라인에서도 동작합니다.

## 개발

```bash
npm install
npm run dev
```

`vite.config.js` 에서 `server.host: true` 로 열어뒀기 때문에, 같은 와이파이의 폰에서 터미널에 찍히는 **Network 주소**(`http://<PC의 IP>:5173`)로 바로 접속해 테스트할 수 있습니다.

```bash
npm run build      # dist/ 생성
npm run preview    # 빌드 결과를 그대로 서빙해서 확인
```

## 배포 (GitHub → Vercel)

1. 이 폴더를 GitHub 저장소로 push
2. Vercel → **Add New → Project** → 저장소 선택
3. Vercel 이 Vite 를 자동 감지합니다. 그대로 두면 됩니다.
   - Framework Preset: **Vite**
   - Build Command: `npm run build`
   - Output Directory: `dist`
4. Deploy

폰에서 주소를 열고 `홈 화면에 추가` 하면 앱처럼 전체화면으로 뜹니다(`public/manifest.webmanifest`).

> `package.json` 의 `allowScripts` 는 npm 11+ 의 설치 스크립트 차단 정책 때문에 필요합니다. esbuild(Vite 의 의존성)가 플랫폼 바이너리를 설치하려면 이 항목이 있어야 빌드가 됩니다. 지우지 마세요.

## 구조

```
index.html              마크업만. /src/main.js 를 불러온다
public/                 그대로 복사되는 정적 파일
  manifest.webmanifest
  icon.svg
src/
  main.js               진입점 — 테마 → 악보 복원 → 렌더 → 이벤트 연결
  constants.js          악기 정의, 팔레트, 저장소 키 (의존성 없음)
  state.js              앱 상태 + 되돌리기 히스토리 (DOM 안 건드림)
  dom.js                DOM 유틸 · 토스트 · 시트 열고닫기 (의존성 없음)
  notation.js           오선 악보 조판 → SVG 문자열
  palette.js            하단 팔레트의 리듬 미리보기
  render.js             화면 그리기 (악보 + 하단 편집 줄)
  actions.js            악보를 바꾸는 동작들 (전부 되돌리기 지점 남김)
  sheets.js             메뉴 · 저장목록 · 내보내기 · 안내 · 섹션 · PDF
  ui.js                 이벤트 연결 (DOM 이벤트를 받는 유일한 곳)
  style.css
```

의존 방향은 한 쪽으로만 흐릅니다 — `constants → state → notation/palette → render → actions → sheets → ui → main`. 순환 참조가 없습니다.

## 쓰는 법

**입력** — 마디를 탭해 선택 → 그 마디 안에서 원하는 박의 **악기 높이**를 탭(스네어면 오선 가운데, 베이스면 맨 아래 칸) → 하단 팔레트에서 리듬 패턴 선택. 넣으면 다음 박으로 자동 이동합니다(메뉴에서 끌 수 있음). 악기는 하단 칩으로도 바꿉니다.

**틱 줄** — 한 박을 나눈 각 틱(16비트면 `1 e & a`)을 손보는 줄. 왼쪽 버튼으로 모드를 바꿉니다.

| 모드 | 하는 일 |
|---|---|
| `악센트` | 탭하면 켜지고 다시 탭하면 꺼집니다. 아무 조합이나 가능 (1만 / 1·& / 1·e·a / 넷 다) |
| `오픈` `벨` `고스트` | 하이햇 `○`, 라이드 `◆`, 스네어 `( )`. 해당 악기에서만 나옴 |
| `악기` | **필인용.** 틱마다 다른 드럼을 찍습니다. 칩에서 악기를 고르고 틱을 탭 |

**그 외** — 4마디 단위 섹션(이름·도돌이표 `×2`~`×4`, 재생에도 반영), 되돌리기, 섹션 중간 삽입/삭제, 저장·불러오기, JSON·텍스트탭 내보내기, PDF 내보내기(A4·한 줄에 4마디), 다크/종이 테마.

## 악보 표기

오선 위에서 아래로: 크래쉬(덧줄 ✕) · 하이햇(✕) · 라이드(✕) · 탐탐 · 스네어 · 플로어탐 · 베이스 · 하이햇페달(덧줄 ✕).

손은 기둥이 위로, 발은 아래로 그리는 2성부. 음표는 박마다 몰지 않고 **마디 전체에 균등 배치**하며, 쉼표는 박의 첫 음표 앞에만 찍습니다(음표 길이가 다음 음표까지 이어지는 표준 조판). 악센트는 음표 꼬리 바깥쪽에 붙습니다.

악보 SVG 는 색을 하드코딩하지 않고 전부 `currentColor` 로 그린 뒤 `.ms svg{color:var(--ink)}` 에서 받습니다. 그래서 테마를 바꿔도 악보가 같이 따라오고, 인쇄할 때만 검정으로 고정됩니다.

## 데이터 모델

```js
song = {
  title, bpm,
  bars: [ bar ]          // 길이는 항상 4의 배수
}

bar = {
  beats: [ beat, beat, beat, beat ],   // 4/4 고정
  sec:   { name, rep }                 // 4마디 섹션의 첫 마디에만. rep = 추가 반복 횟수
}

beat = {
  HH: { d, s }, SN: { d, s }, BD: { d, s },   // 악기별로 분할이 달라도 됨
  CR: …, RD: …, TT: …, FT: …, HF: …
}
// d = 그 박의 분할수 (1 · 2 · 3 · 4 · 6)
// s = 길이 d 배열. '' 없음 | 'n' 보통 | 'a' 악센트 | 'o' 오픈 | 'g' 고스트 | 'b' 벨
```

한 박 안에서 악기마다 분할이 달라도 되고(하이햇 8분 + 스네어 16분), 그릴 때 최소공배수 격자로 합쳐 정렬합니다.

저장은 `localStorage` 를 씁니다(`drumcopy.v4.songs`). **주소(origin)마다 저장소가 따로**라 로컬에서 저장한 악보는 배포 주소에서 안 보입니다. 옮기려면 메뉴 → 내보내기에서 JSON 복사 → 반대쪽에서 가져오기.
