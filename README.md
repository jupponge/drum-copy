# DrumCopy — 모바일 드럼 사보

한 박 단위로 리듬을 채워넣어 드럼 악보를 카피하는 웹앱. 빈 오선지에서 **마디 → 박 + 오선 위치(악기) → 리듬 패턴** 순서로 탭해서 채웁니다. 외부 라이브러리·폰트·이미지를 쓰지 않는 단일 파일이라 한 번 열어두면 오프라인에서도 동작합니다.

## 배포 (GitHub → Vercel)

빌드가 없는 정적 사이트입니다. Vercel에서 별도 설정이 필요 없습니다.

1. 이 폴더를 GitHub 저장소로 push
2. Vercel → **Add New → Project** → 저장소 선택
3. Framework Preset: **Other**, Build Command: **비움**, Output Directory: **비움**(루트)
4. Deploy

루트의 `index.html` 이 그대로 서빙됩니다. 폰에서 주소를 열고 `홈 화면에 추가` 하면 앱처럼 전체화면으로 뜹니다(`manifest.webmanifest`).

## 파일

| 파일 | 설명 |
|---|---|
| `index.html` | 앱 전체 (마크업 · 스타일 · 로직) |
| `manifest.webmanifest` | 홈 화면 추가용 |
| `icon.svg` | 앱 아이콘 |
| `_old/` | 예전 버전. `.gitignore` 로 제외됨 |

## 쓰는 법

**입력** — 마디를 탭해 선택 → 그 마디 안에서 원하는 박의 **악기 높이**를 탭(스네어면 오선 가운데, 베이스면 맨 아래 칸) → 하단 팔레트에서 리듬 패턴 선택. 넣으면 다음 박으로 자동 이동합니다(메뉴에서 끌 수 있음).

**틱 줄** — 한 박을 나눈 각 틱(16비트면 `1 e & a`)을 손보는 줄. 왼쪽 버튼으로 모드를 바꿉니다.

- `악센트` — 탭하면 켜지고 다시 탭하면 꺼집니다. 아무 조합이나 가능
- `오픈 / 벨 / 고스트` — 하이햇 `○`, 라이드 `◆`, 스네어 `( )`
- `악기` — **필인용**. 틱마다 다른 드럼을 찍습니다. 악기 칩을 고르고 틱을 탭

**그 외** — 4마디 단위 섹션(이름·도돌이표 `×2`~`×4`, 재생에도 반영), 되돌리기, 섹션 중간 삽입/삭제, 저장/불러오기(기기 내), JSON·텍스트탭 내보내기, PDF 내보내기(A4·한 줄에 4마디), 다크/종이 테마.

## 악보 표기

오선 위에서 아래로: 크래쉬(덧줄 ✕) · 하이햇(✕) · 라이드(✕) · 탐탐 · 스네어 · 플로어탐 · 베이스 · 하이햇페달(덧줄 ✕).
손은 기둥이 위로, 발은 아래로 그려집니다. 음표는 박마다 몰지 않고 **마디 전체에 균등 배치**하며, 쉼표는 박의 첫 음표 앞에만 찍습니다(음표 길이가 다음 음표까지 이어지는 표준 조판).

## 데이터 모델

```js
song = {
  title, bpm,
  bars: [ bar ]          // 길이는 항상 4의 배수
}

bar = {
  beats: [ beat, beat, beat, beat ],   // 4/4 고정
  sec:   { name, rep }                 // 4마디 섹션의 첫 마디에만. rep = 추가 반복 횟수
}

beat = {
  HH: { d, s }, SN: { d, s }, BD: { d, s },   // 악기별로 분할이 달라도 됨
  CR: …, RD: …, TT: …, FT: …, HF: …
}
// d = 그 박의 분할수 (1 · 2 · 3 · 4 · 6)
// s = 길이 d 배열. '' 없음 | 'n' 보통 | 'a' 악센트 | 'o' 오픈 | 'g' 고스트 | 'b' 벨
```

한 박 안에서 악기마다 분할이 달라도 되고(하이햇 8분 + 스네어 16분), 그릴 때 최소공배수 격자로 합쳐 정렬합니다.

저장은 `localStorage` 를 씁니다(`drumcopy.v4.songs`). **주소(origin)마다 저장소가 따로**라 PC에서 저장한 악보는 배포 주소에서 안 보입니다. 옮기려면 메뉴 → 내보내기에서 JSON 복사 → 반대쪽에서 가져오기.
